# JavaScript Exercises 

This folder contains a collection of JavaScript exercises I completed while learning the fundamentals of the language. The exercises are organized by topic, with each folder focusing on a specific concept.

## Repository Structure

Each topic folder includes:
- `0.Assignment-Instructions.md` → Description of the exercises
- `.js` files → My solutions to each exercise

### Topics Covered

- **01 - Intro**
  - Basic syntax, variables, and simple operations

- **02 - Control Structures**
  - Conditionals (`if`, `else`, `switch`)
  - Loops (`for`, `while`)

- **03 - Arrays**
  - Array manipulation and iteration

- **04 - Functions**
  - Function declarations, expressions, and parameters

- **05 - Objects**
  - Object creation and property handling

- **06 - Classes**
  - ES6 classes and object-oriented programming basics

## Purpose

The goal of this repository is to:
- Practice core JavaScript concepts
- Track learning progress over time
- Serve as a reference for fundamental patterns and syntax
